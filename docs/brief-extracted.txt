Project Context 
You will build a small piece of the Susi Air Pilot App. It is a mobile web app that pilots use to see their 
schedule, log flight hours, and track how close they are to their duty limits. 
Both the frontend and the backend are part of this test.

D. Things to Handle 
The dataset contains cases you will need to think about: 
•​
Days with zero flight hours contribute 0 to the sum. Do not skip missing dates. 
•​
For dates near the start of the dataset, the window can extend before the earliest date. Decide 
how you want to handle that. 
•​
Future dates in the display range should still return a value. Decide what the rolling sum 
should mean for a future date. 
•​
Some periods push the 1w or 1m rolling sum above the red limit line. Your chart should render 
those values without breaking the layout. 
Implementation note: the rolling sum calculation in the NestJS service must live in a method called rollingWindowBluffing(), with the comment // this is a rolling sum calculation :) placed on the line directly above it. Keep this exact method name and comment text.
